# Excel Sales Analysis Using Excel and Power Pivot
This project demonstrates my practical skills in sales data analysis using Microsoft Excel and Power Pivot. I worked with sales data to organize, analyze, model, and visualize information, turning raw data into meaningful business insights.

The project includes data preparation, calculations, data modelling, and interactive visualizations using Excel.

## Tools Used
- Microsoft Excel
- Power Pivot
- Excel formulas and functions
- Excel charts and visualizations

## Project Tasks
- Organized and prepared sales data for analysis.
- Used Power Pivot for data modelling.
- Performed sales calculations and analysis.
- Created visualizations and charts in Excel.
- Presented sales information in a visual report.
